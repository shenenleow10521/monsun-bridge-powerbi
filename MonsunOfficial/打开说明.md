# 打开官方数据版

1. 下载整个仓库 ZIP，右键选择「全部解压」。不要从压缩包窗口直接打开。
2. 进入解压后的 `MonsunOfficial` 文件夹。
3. 用支持 PBIP/PBIR 的 Power BI Desktop 打开 `MonsunOfficial.pbip`。
4. 点击「刷新」。本版本的数据已经嵌入模型，不需要配置 CSV 路径或登录数据源。
5. 检查四页及筛选器。确认后「另存为」PBIX，并从 Desktop 导出 PDF。

`MonsunOfficial.pbip`、`MonsunOfficial.Report` 和 `MonsunOfficial.SemanticModel` 必须保持在同一个文件夹内，不要只复制 PBIP。

初始检查：P1 的 2025 Q4 游客数应为 74.0 million；METMalaysia NEMI 记录的 2024/25 东北季风窗口应为 13 November 2024 至 25 March 2025，共 133 天。P2 不筛选县时，就业总人数应为 210,200。P4 默认参与率为 5%、培训 1 个月、每人月 RM1,100、行政费为培训费的 10%，情景总额应为 RM12,717,100。

数据含义：就业数涵盖全部行业，不是旅游受影响工人数。P4 是预算情景；P3 尚没有经过核实的技能匹配结果。不同数据集的年份已显示，未使用这些错期数据计算 CSI。P1 的两个季风窗口是 METMalaysia 研究报告里的已观测 NEMI 结果，不是长期预测序列。

这是新增的官方数据基础版；旧项目保留在仓库根目录。此环境未运行 Windows Power BI Desktop，因此尚未确认实际渲染、刷新和交互，不能把结构检查当成 Desktop 测试通过。
